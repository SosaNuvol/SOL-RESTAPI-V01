# Solasta-ERP-System

This folder contains a proposed design for Solasta's lighting installation business. No application code, database migrations, or deployments have been created. Review the language recommendation and business decisions before implementation.

- [Technology recommendation](docs/technology.md)
- [Business workflows and application architecture](docs/architecture.md)
- [SQL Server logical data model](docs/data-model.md)
- [Installation records, topology, and mobile workflows](docs/installation-and-service.md)
- [Implementation phases and decisions to resolve](docs/roadmap.md)

The initial scope covers leads, customers, sales attribution, properties, installations, equipment costs, installer compensation, warranty service, and GoHighLevel lead ingestion. Full accounting, payroll, purchasing, and inventory replenishment are later modules unless required for launch.
